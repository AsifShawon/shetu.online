# EduWise V3 Frontend

Next.js 16 App Router frontend for the EduWise V3 clone.

## Stack

- Next.js 16+
- TypeScript
- Tailwind CSS
- shadcn-style component setup
- Framer Motion

## Areas

- public pages
- auth pages
- student dashboard
- consultant dashboard
- agency dashboard
- admin portal

## Notes

- The current implementation is a structured foundation and route shell aligned with `PLAN.md`.
- It is designed to consume the Django backend under `../backend`.
