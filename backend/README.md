# EduWise V3 Backend

Django + DRF backend for the EduWise V3 clone.

## Domains

- accounts
- content
- catalog
- students
- consultants
- assessments
- payments
- agencies
- marketplace
- admin_portal

## Notes

- This backend is scaffolded around the migration plan in `PLAN.md`.
- Dependencies are declared in `requirements.txt`.
- Migrations are not generated yet because Django is not installed in the current workspace.
