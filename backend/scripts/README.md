# Import Scripts

`import_v2.py` is the entry point for V2 to V3 data migration.

Planned migration order:

1. users and admins
2. content and site settings
3. catalog entities
4. student data
5. consultant data
6. assessments and reports
7. payments and orders
8. agencies
9. marketplace

The script is scaffolded and ready to be expanded once the backend dependencies are installed and migrations are generated.
